01 About

I work close to the people who depend on what I build — wind fleet operators, pharma QA teams, clinical researchers, retail planners. The constraints that matter come from them rather than from the dataset, which is why I'd rather start with the domain expert than the schema.

The work spans classical ML, deep learning, and the systems around both. An LSTM–Transformer autoencoder scoring 3,400 turbines off a billion SCADA records. A LLaMA model pretrained on 600M patient visits across an 8-GPU cluster, benchmarked against the traditional baselines it had to beat. Retrieval over CAPA reports and SOPs inside a regulated QA workflow. Segmentation and hypothesis testing for retail clients, and the Pandas-to-PySpark migration that made it affordable.

I ship it as software rather than as notebooks: typed interfaces, unit tests, CI, migrations, infrastructure as code, and evaluation harnesses that measure outcomes rather than the model's own account of them. Electrical engineering before ML — which is where the bias toward instrumentation and failure modes comes from.

Calendar.ai

Mar 2026

Turns “gym, study 2 hours, groceries” into a booked day that doesn't double-book you.

The decision I'd defend in a review: the calendar tools are closed over a per-user client, so the model never sees a user ID. Cross-tenant access isn't something the prompt prevents — it's structurally impossible.

The evals score the resulting calendar state, not what the model says it did. That's what catches double-bookings and buffer violations a transcript check would happily pass.

Timezones were the real enemy — scheduling in user-local time from a container running UTC. 82 unit tests, 10 ADRs, and a destroy.sh, because it costs ~$30/month to leave running.

Real-Time Voice Agent

Apr 2026

Runs mock interviews over voice, then grades how you did.

Audio streams bidirectionally over WebSockets through FastAPI into the OpenAI Realtime API. The part worth talking about is the state split: transcripts accumulate in Redis while the session is live, then migrate to PostgreSQL on completion, where the performance gets scored.

The agent pulls your prior history before it speaks, so the opening question is informed by how you did last time — and it can reach for web search mid-conversation.

Real-time audio punishes latency anywhere in the path, which is why session state lives in Redis and never touches Postgres until the call ends.

Repo Explainer — MCP Server

Feb 2026

Copilot and Cursor reason about your repo from stale training data. This gives them the live one.

Five tools over the GitHub API — summarize_repo, explain_file, ask_repo, recent_changes, analyze_dependencies — with no cloning required. The dependency tool cross-references PyPI to flag what's gone stale.

Scoped to a read-only token by design: it's a tool you point at other people's repositories, so it should never be able to write to one.

Published to PyPI, so it's a one-line install into any MCP-compatible editor rather than a repo you have to clone and wire up.
